# Sanad Research Paper — Build Pipeline

The paper at `public/Sanad_Mental_Health_Research.docx` is **generated** from this
directory. Do **not** hand-edit the `.docx` in Word — changes there will be lost on
the next rebuild. Edit the scripts instead.

## Files

| File | Purpose |
|------|---------|
| `build.py` | Document content + structure (cover, sections, tables, references). |
| `style.py` | Styling engine: teal palette, heading styles, table theming, footer, TOC. |
| `charts.py` | Generates the 5 figures (4 infographics + architecture diagram) into `figures/`. |
| `assets/` | Cover logos (`image1.gif`, `image2.jpg`). |
| `figures/` | Generated chart PNGs (regenerated by `charts.py`). |

## Rebuild

```bash
cd tools/research-paper
pip3 install python-docx Pillow matplotlib   # first time only
python3 charts.py     # regenerate figures (only if charts.py changed)
python3 build.py      # rebuild the .docx
```

> Close the document in Word before rebuilding, or the overwrite may fail.

### Dry run (don't overwrite the live paper)

```bash
SANAD_PAPER_OUT=/tmp/preview.docx python3 build.py
```

## Verify (optional)

Requires LibreOffice + `pypdf` (`pip3 install pypdf`):

```bash
/Applications/LibreOffice.app/Contents/MacOS/soffice --headless \
  --convert-to pdf --outdir /tmp ../../public/Sanad_Mental_Health_Research.docx
python3 -c "from pypdf import PdfReader; print(len(PdfReader('/tmp/Sanad_Mental_Health_Research.pdf').pages), 'pages')"
```

## After rebuilding

Open in Word → right-click the Table of Contents → **Update Field** to populate it.
